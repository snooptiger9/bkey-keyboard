# Trademark & Branding

The source code of bkey is open source under the [GNU GPL v3](LICENSE). The name and the visual identity of the project are **not** part of that grant. This page explains what that means in practice.

## What is covered

- The name **"bkey"** and **"bkey Plus"**, and names that are confusingly similar to them.
- The bkey logo and app icon.
- The README banner images and other branding assets of the project.
- The application ID `com.snooptiger9.bkey`, as the identity of the official app on app stores.

## What the GPL still allows

Nothing in this page changes the license of the code. You can still:

- Use, study, modify and share the source code under the terms of the GPL v3.
- Fork the repository on GitHub. GitHub keeps the repository name when you fork, and that is fine.
- Redistribute the official, unmodified releases.
- Write about bkey, review it, link to it, and say that your project is "based on bkey" or "a fork of bkey", as long as it is accurate and does not suggest that we made or approve it.

## What is not allowed without permission

- Naming a fork or derivative app "bkey", "bkey Plus", or anything easily confused with them.
- Using the bkey logo or app icon in a modified version, or in a way that makes people think it is the official app.
- Publishing a modified version on an app store, website or social account under the bkey name, logo or application ID.
- Promoting a fork or derivative app using the bkey name or branding, or implying that it is endorsed by this project.

## Asking for permission

If you would like to use the name or the branding for something specific, open an issue on this repository or email **lvl60me@gmail.com** and describe the use. Permission, if given, is given in writing.

## Reporting misuse

If you find an app, store listing or website that uses the bkey name, logo or application ID without permission, please open an issue with the link, or email the address above.

_This page is a statement of how the project's name and branding may be used. It is not legal advice._
