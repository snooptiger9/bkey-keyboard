### Release v306.0

- **Hindi keyboard:** Hindi (Devanagari, InScript layout) is now the fourth language. It has its own dictionary, next-word prediction, typo corrections, emoji suggestions, learned words, voice typing language, and Hindi text in the clipboard, emoji and GIF panels. It uses the danda (।), Devanagari digits and the rupee sign.
- **Spanish emoji suggestions:** Typing common Spanish words like amor, gracias or feliz now suggests an emoji, only while the Spanish keyboard is active.
- **Cleaner APK:** The signed APK no longer contains the Google dependency-info block.
- **Docs:** A Hindi README, and Hindi added to the language lists.
